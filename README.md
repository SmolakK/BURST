# BURST

**Balanced Urban Recommenders for Sustainable Mobility Transitions**

A WIP repository for the BURST project funded by the Polish NAWA Agency. This repo hosts
general project-related files and the public project website.

🌐 **Project site: <https://smolakk.github.io/BURST/>**

## About the project

Urban Recommenders (URs) such as Google Maps, Uber and TripAdvisor have become integral to
human mobility. Designed for individual convenience, they often produce unintended
consequences: congestion, pollution and urban segregation. BURST focuses on the *spatial
filter bubbles* created by URs, where users are repeatedly nudged toward the same
destinations and routes, reinforcing spatial inequalities.

The project diagnoses, measures and mitigates these effects. Building on human mobility
models, traffic microsimulations and causal analysis through quasi-experiments, it develops
new metrics for detecting spatial filter bubbles and designs **Balanced Urban Recommenders
(BURs)** that promote diversity, sustainability and spatial justice. Outputs include
open-source digital twins, datasets and BUR prototypes.
